# Cybersecurity Lab Write-ups

A growing collection of hands-on cybersecurity lab notes, CTF walkthroughs, and penetration-testing write-ups.

This repository documents practical learning across web application security, offensive security, network enumeration, and related topics. Each write-up aims to explain the methodology and reasoning, not just list commands.

## Topics

- Web application security: SQL injection, XSS, authentication, access control, file upload, and more
- Enumeration and reconnaissance
- Network security
- Active Directory security
- Vulnerability analysis and remediation

## Tools

Burp Suite, Nmap, Wireshark, Metasploit, SQLmap, Gobuster, Linux, and other tools used where relevant.

## How to use this repository

Browse a platform folder to find its labs. Write-ups may include the lab objective, scope, methodology, evidence, findings, impact, remediation, and lessons learned.

## Disclaimer

All testing documented here is performed in authorized labs, CTF environments, or systems where permission has been granted. Do not use these techniques against systems without explicit authorization. Platform-specific rules and disclosure policies are respected; restricted flags, answers, or walkthrough content will not be published.
